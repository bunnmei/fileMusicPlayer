# Music Player

端末に保存した音楽ファイルを再生する、シンプルな Android 用音楽プレイヤーです。
Jetpack Compose（Material 3）と Media3（ExoPlayer）で作っています。

## 主な機能

- **ライブラリ**: 端末内の曲を自動で読み込み、「アルバム」「曲」「アーティスト」のタブで表示
- **検索**: 曲名・アルバム名・アーティスト名で絞り込み
- **再生画面**: 大きなジャケット、シークバー、シャッフル、リピート（全曲 / 1 曲）、再生キュー
- **ミニプレイヤー**: どの画面でも下部から再生・一時停止・次の曲を操作
- **バックグラウンド再生**: 画面を消しても、ほかのアプリを使っていても再生が続く。通知・ロック画面・イヤホンや Bluetooth 機器のボタンで操作可能。イヤホンを抜くと自動で一時停止
- **設定**
  - テーマ: システム / ライト / ダーク（Android 12 以降は壁紙の色を使う「ダイナミックカラー」も選択可）
  - アプリ内の音量: 端末の音量とは別に、このアプリだけの音量をスライダーで調整
  - イコライザー: プリセット、または周波数帯ごとのスライダーで調整
  - 低音・立体音響: 低音ブースト、バーチャライザー（イコライザーをオンにすると表示。端末が対応している場合のみ）
  - 表示するフォルダ: 曲が入っているフォルダをツリーで一覧し、チェックを外したフォルダ（とその中のフォルダ）をライブラリから隠す
  - ライブラリの再スキャン

## 音楽ファイルの置き場所

**フォルダの決まりはありません。** Android が管理している「メディアの索引（MediaStore）」から曲を読み込むので、
端末の内部ストレージや SD カードのどこに置いても表示されます。迷ったら `Music` フォルダに入れてください。

おすすめの構成:

```
内部ストレージ/
└── Music/
    └── アーティスト名/
        └── アルバム名/
            ├── 01 曲名.mp3
            ├── 02 曲名.mp3
            └── cover.jpg      ← ジャケット画像（任意）
```

### 曲の情報（タグ）

タイトル・アーティスト・アルバム・トラック番号は、ファイルに埋め込まれたタグ（MP3 の ID3 タグなど）から読み取ります。
PC の音楽管理ソフト（iTunes / Mp3tag / foobar2000 など）でタグを付けておくときれいに整理されます。

- **アルバム**: 同じアルバム名のタグを持つ曲が 1 枚のアルバムになります
- **曲順**: トラック番号（ディスク番号）の順。タグが無いときはファイル名先頭の数字（`01曲名.mp3` など）を使います
- **タイトル**: タグが無いときはファイル名を使います。先頭の番号がトラック番号と同じなら、表示時に取り除きます（`01素敵なハート` → `素敵なハート`）
- **ジャケット画像**: ファイルに埋め込まれた画像を優先し、無ければ同じフォルダの画像を使います。
  画像が複数あるときは `cover` / `folder` / `front` / `album` / `albumart` / `jacket` という名前（拡張子は jpg / png など）が優先されます

### 曲を端末にコピーする

1. PC と端末を USB ケーブルでつなぎ、端末側で「ファイル転送」を選ぶ
2. PC から端末の `Music` フォルダにアルバムごとのフォルダをコピーする
3. アプリを開くと自動で一覧に追加されます。出てこないときは **設定 → ライブラリを再スキャン** を押してください

### 同じ曲が 2 回表示されるとき

端末全体から曲を集めるので、別のアプリが同じ曲をコピーしていると重複して表示されます
（例: Huawei のクラウドドライブが展開した `Huawei/CloudDrive/extractfiles/` 内の曲）。
**設定 → 表示するフォルダ** で、そのフォルダのチェックを外してください。ファイルは削除されません。

> `.nomedia` というファイルがあるフォルダは Android がメディアとして扱わないため、表示されません。
> 5 秒未満の音声（通知音など）も表示しません。

### 対応形式

MP3 / AAC（m4a）/ FLAC / Ogg Vorbis / Opus / WAV など、ExoPlayer と端末が対応している形式。

## 権限

| 権限 | 用途 |
| --- | --- |
| 音楽とオーディオ（Android 12 以前は「ストレージ」） | 曲の一覧表示と再生（必須） |
| 写真と動画 | フォルダ内のジャケット画像の表示（任意） |
| 通知 | 再生中の曲の通知とその操作ボタン（任意） |

## ビルド方法

### 必要なもの

- Android Studio（最新の安定版）または JDK 17 以上
- Android SDK Platform 37

### コマンドライン

```bash
# デバッグ版のビルド（パッケージ名は space.webkombinat.musicplayer.debug）
./gradlew assembleDebug

# ユニットテスト・lint
./gradlew testDebugUnitTest lintDebug

# 接続した端末にインストール
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

デバッグ版はパッケージ名の末尾に `.debug` が付くので、リリース版と同時にインストールできます。

### 主なバージョン

| 項目 | バージョン |
| --- | --- |
| Gradle | 9.8.1 |
| Android Gradle Plugin | 9.4.1 |
| Kotlin | 2.4.21 |
| Compose BOM | 2026.09.00 |
| Media3 | 1.11.1 |
| compileSdk / targetSdk | 37 |
| minSdk | 26（Android 8.0） |

ライブラリのバージョンは `gradle/libs.versions.toml` にまとめてあります。

## プロジェクト構成

```
app/src/main/java/space/webkombinat/musicplayer/
├── MusicApp.kt                 Application（Hilt の起点）
├── MainActivity.kt             テーマの適用と画面の起点
├── data/
│   ├── model/Models.kt         Song / Album / Artist / Library
│   ├── MediaStoreSource.kt     MediaStore から曲とジャケット画像を読む
│   ├── MusicRepository.kt      ライブラリの保持・変更の監視・除外フォルダの反映・再スキャン
│   ├── LibraryBuilder.kt       曲をアルバム・アーティストにまとめて並べる
│   ├── FolderTree.kt           「表示するフォルダ」画面用のフォルダツリー
│   ├── SettingsRepository.kt   設定の保存（DataStore）
│   └── TitleFormatter.kt       タイトルとトラック番号の整形
├── playback/
│   ├── PlaybackService.kt      バックグラウンド再生（MediaSessionService + ExoPlayer）
│   ├── PlayerController.kt     UI から再生を操作する窓口（MediaController）
│   └── AudioEffectsController.kt  イコライザー・低音ブースト・バーチャライザー
└── ui/
    ├── MusicPlayerApp.kt       画面遷移とミニプレイヤーの配置
    ├── permission/             権限のお願い画面
    ├── library/                ライブラリ・アルバム詳細・アーティスト詳細
    ├── player/                 ミニプレイヤー・再生画面
    ├── settings/               設定画面・表示するフォルダ画面
    ├── components/             共通部品（ジャケット画像・リスト行など）
    └── theme/                  色・文字・テーマ
```

## 旧バージョンからの変更点

旧バージョンは `内部ストレージ/Music/Records/01アルバム名/01曲名.mp3` という番号付きフォルダしか読めませんでしたが、
このバージョンではどこに置いた曲でも読み込めます。既存の `Music/Records` フォルダはそのままで表示されます。
